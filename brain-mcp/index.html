brain-mcp

agent memory in Obsidian

github.com/dck/brain-mcp

brain-mcp is a memory for AI coding agents, stored as an Obsidian vault.

It works as an MCP server: agents save what they learn and find it later, in any project.

Every note is a markdown file in Obsidian. You can read it, edit it and see how notes link to each other.

I made it so all my agents (Claude Code, Codex and others) share one memory.
